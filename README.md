# Sleep Disorder Prediction System

A machine-learning web application built using Python, Flask, and Scikit-learn.

## Features
- Predicts sleep disorder categories based on lifestyle information
- Interactive web interface
- Trained machine-learning classification model

## Technologies
Python, Flask, Scikit-learn, Pandas, HTML, CSS

## How to Run
Install the required Python libraries, then run `py app.py` and open `http://127.0.0.1:5000`.

## Dataset
Sleep Health and Lifestyle Dataset by Laksika Tharmalingam, available on Kaggle:
https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset
